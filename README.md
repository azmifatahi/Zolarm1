# زولارم (Zolarm)

منبّه بصعوبة عالية — لا يُغلق إلا بعد تحدّي خطوات أو التحقق بالوجه.

## المميزات
- منبّه دقيق (`setAlarmClock`) فوق شاشة القفل
- تحدي الخطوات (مستشعر الخطوة)
- تحدي الكاميرا: وجه + حركة + عين/فم مفتوح ثم التقاط تلقائي وإيقاف المنبّه
- تبديل كاميرا أمامية/خلفية
- لغة عربية افتراضية
- قائمة: حول التطبيق + بحث وتثبيت تحديث من GitHub Releases
- تحديث تلقائي عند فتح التطبيق (يتطلب APK في الـ Release)
- خدمة أمامية + إعادة جدولة بعد الإقلاع
- توقيع ثابت في CI لتفادي فشل التثبيت

## البناء على GitHub
ادفع إلى `main` → Actions → حَمّل Artifact **Zolarm-debug-apk** → فك الضغط → ثبّت `Zolarm-debug.apk`

## التحديث التلقائي
أنشئ Release بوسوم أعلى من `2.0.0` (مثل `v2.0.1`) وارفع ملف `.apk` كـ asset.
